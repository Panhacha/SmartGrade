# Smart Grade Entry

Smart Grade Entry is an AI-powered grading system that automates the extraction and verification of scores from scanned exam papers using OCR technology.

## Features
- Scan and upload student exam papers.
- Automatically recognize Student IDs and scores using AI (Tesseract OCR & Jimp pixel manipulation).
- Beautiful, intuitive verification UI for teachers.
- Student Roster management and analytics.

## Technologies
- **Frontend**: React, Vite, TailwindCSS, Lucide Icons
- **Backend**: NestJS, Prisma, SQLite/PostgreSQL, Tesseract.js, Jimp
